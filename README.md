# Yabing Masalon Dulo: A Digital Tribute

## Project Overview

This website is a digital tribute dedicated to preserving and celebrating the life, work, and legacy of Yabing Masalon Dulo, a Filipino National Living Treasure (Gawad Manlilikha ng Bayan) and master of B'laan suksuk weaving. The project serves as an educational resource and memorial to her extraordinary contributions to Philippine cultural heritage.

## 🎯 Project Purpose

- To digitally preserve the artistry and legacy of Yabing Masalon Dulo
- To educate visitors about B'laan weaving traditions and suksuk patterns
- To create an immersive experience that honors indigenous cultural heritage
- To make this cultural knowledge accessible to a global audience
